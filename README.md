# CafeApp

Пример задания демонстрационного экзамена.

## Будет полезно

- Connection string можно поменять в CafeDbContext.cs
- Есть миграции (все таблицы при запуске приложения будут созданы автоматически, достаточно просто подключиться к БД)
- При запуске приложения автоматически создается 3 роли (Администратор, официант и повар) и админ (данные для входа можно посмотреть в App.axaml.cs)
- Структуру БД можно изменить, достаточно просто поменять настройки сущностей в CafeDbContext.cs и в терминале ввести команду `dotnet-ef migrations add НАЗВАНИЕ_МИГРАЦИИ`
